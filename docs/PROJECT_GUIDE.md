# newPRAsystem 项目说明

面向使用与评估者。回答三个问题：这是什么、怎么用、能干什么不能干什么。

---

## 1. 产品定位

**一个将企业业务网页自动转化为可配置、可复用、可定时运行的机器人任务的平台。**

解决的问题：业务人员需要定期从业务系统导出报表、上传文件，但传统 RPA 要先录制流程、网页一改就要重录，AI 网页 Agent 又只能一次性操作难以沉淀。

本产品的思路：**让网页本身成为自动化任务的配置来源**——平台解析网页上已有的筛选条件和操作按钮，把它们变成任务配置界面；用户选好条件、设好频率，任务即可长期运行。调整条件时改的是配置，不是脚本。

## 2. 用户与典型场景

| 角色 | 用法 |
|---|---|
| 一线业务人员 | 每周导出经营报表：选日期范围、区域、状态，每周一 9 点自动跑，产物平台下载或邮件送达 |
| 数据运营 | 同一报表页面建多个任务（华东日报 / 华南周报 / 指定产品月报），各跑各的周期 |
| 自动化平台管理员 | 登记目标系统与账号（凭证加密）、维护页面档案、查看运行日志与失败原因 |

**两类交付方式**：
1. 平台内托管：cron 定时调度、运行历史、产物管理、邮件/飞书通知
2. 导出任务包：下载 zip（自包含脚本 + `task_config.json` 配置文件）。交给「小龙虾」或任意调度平台后，员工只改配置文件——自己的账号密码、自己的产物输出目录——无需碰脚本本身

## 3. 操作流程（五步）

1. **登记目标系统**：填登录页 URL、账号密码（Fernet 加密存储）。国内外常见登录页自动识别，特殊页面可配置自定义定位
2. **接入向导**：选系统 + 输入报表页 URL → 平台自动解析（约 20~60 秒）→ 人工确认字段（改业务名称、勾选纳入、补充说明）
3. **创建任务**：像填表单一样选条件——日期用预设（"最近 7 天"/"上周"，每次运行自动换算）或自定义区间，多选/下拉来自网页真实选项；选择动作（导出/查询/提交），可勾前置动作（如"先查询后导出"）
4. **运行与交付**：手动立即运行，或按 cron 定时（预设 + 自定义表达式）；产物、截图、步骤日志全部留痕
5. **持续维护**：
   - 改条件 → 任务编辑页直接改配置保存，立即生效
   - 网页改版新增了筛选项 → 「更新页面档案」重新解析 → 新字段高亮「新增」→ 确认纳入后即可在任务中使用，**老任务不受影响**

## 4. 能力地图

| 能力 | 支持情况 |
|---|---|
| 组件体系 | Ant Design、Element UI / Element Plus、OrangeHRM(oxd)、原生表单 |
| 登录方式 | 账号密码型登录页（中英文自动识别）；登录态按系统缓存复用，失效自动重登 |
| 字段类型 | 日期区间（含相对预设）、单选/多选下拉、文本、上传、单选/复选组 |
| 调度 | cron（每天/每周/每月/自定义），时区 Asia/Shanghai |
| 通知 | 邮件、飞书群机器人 webhook |
| 产物 | 导出文件下载、每步截图、运行摘要 JSON |
| 凭证安全 | Fernet 对称加密，密钥自动生成 |
| 任务资产化 | 编辑、副本（多版本场景）、档案版本化更新、导出独立脚本 |

## 5. 能力边界（诚实清单）

| 不支持 / 受限 | 说明 |
|---|---|
| **验证码类登录** | 图形验证码（JeecgBoot、若依官方 demo）、登录后营销拦截（芋道演示站）无法全自动接入。规划中的解法：浏览器插件人工辅助——人过一次验证码，会话交给平台复用 |
| 企业 SSO / 短信 / 扫码登录 | 属上一条边界 |
| 树形/级联选择组件 | 尚无适配（现有组件体系已覆盖常见后台表单） |
| 下载类动作之外的产物语义 | 对"导出文件"最成熟；纯查询结果的抓取展示较弱（可后续加表格数据提取） |
| 并发大量任务 | 当前为线程并发起浏览器，量大需队列 |

**真实系统实测结论**（公网演示站）：
- ✅ 成功接入：OrangeHRM（国际 HR 系统）、苦糖果 MES（国内制造业，RuoYi 体系）、vue-element-admin
- ❌ 受阻于反自动化门槛：JeecgBoot（图形验证码）、芋道（扫码营销拦截）——均截图确认是站点主动设防，非引擎缺陷

## 6. 技术栈与部署

- 前端 React 18 + Ant Design 5；后端 FastAPI + SQLAlchemy + APScheduler；自动化引擎 Playwright；数据库 PostgreSQL 17
- LLM（GLM）用于字段语义化命名，可选未配置时自动降级为规则命名，功能不受阻
- **部署**：标准命令见 README「快速开始」（Windows / Linux 均可）；Windows 另有 `setup.ps1`（首次）→ `start.ps1`（日常）一键脚本；详细运维见交接文档

## 8. 常见问题

**Q：任务运行失败怎么排查？**
任务详情 → 运行历史 → 失败记录看 error 文案（登录类失败会附页面原始错误提示）与 error.png 截图、run_summary.json 步骤日志。

**Q：目标网页改版了任务会挂吗？**
小改（结构微调）由语义定位自愈；新增字段走「更新页面档案」纳入；字段被删除会明确报"字段不在档案中"。

**Q：密码安全吗？**
平台内 Fernet 加密存储，密钥在 server/.env（首次自动生成）。**注意：.env 丢失则已存密码无法解密**，请备份。导出的任务包中，密码放在 `task_config.json`（默认预填，可导出时选择留空由员工自行填写），脚本本身不含密码——配置文件需妥善保管。

**Q：想回退到 SQLite？**
`server/.env` 里 `DATABASE_URL` 改回 `sqlite:///./newpra.db` 即可，表结构兼容。
